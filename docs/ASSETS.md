# Ресурсы проекта

Графические файлы SVG масштабируются без потери качества. Эмблемы эпох можно использовать в меню выбора эпохи, карточках заданий или загрузочных экранах. `rune-floor.svg` — декоративная текстура для рунических поверхностей.

Звуки WAV локальные и не требуют внешних аудиосервисов. В браузерах воспроизведение звука разрешается после первого действия пользователя.
